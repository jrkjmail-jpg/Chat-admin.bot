# Chat Admin Bot

Telegram AI-администратор для родительских чатов студии.

## Что умеет MVP

- Работает в родительских чатах.
- Принимает текст, PDF, Word (`.docx`), Excel (`.xlsx`, `.xls`), изображения и голосовые сообщения в личном чате администратора или сервисном чате.
- Добавляет знания только после подтверждения администратора.
- Отвечает через OpenAI API только на основании сохранённой базы знаний.
- Если ответа нет, пишет: «Передаю ваш вопрос администратору.»
- Поддерживает режимы работы бота по расписанию.
- Для каждой родительской группы отдельно умеет отвечать либо только на вопросы, либо на каждое сообщение.
- Удаляет сообщения с подозрительными ссылками или рекламой.
- Через AI анализирует контекст переписки и предупреждает группу при нарастающем споре, грубости, оскорблениях или угрозах.

## Важно про хранение данных

Репозиторий публичный, поэтому в GitHub нельзя хранить базу знаний, PDF, настройки, чаты, токены и любые реальные данные студии.

Все рабочие данные MVP должны храниться только в постоянной папке BotHost:

```text
/app/data
```

Для SQLite используйте путь:

```env
DATABASE_PATH=/app/data/studio_admin.db
```

Так данные сохраняются между обновлениями из GitHub, пересборками Docker-образа и перезапусками контейнера.

## Переменные окружения

Создайте переменные в BotHost или в `.env` локально:

```env
BOT_TOKEN=telegram_bot_token
OPENAI_API_KEY=openai_api_key
ADMIN_IDS=123456789,987654321
SERVICE_CHAT_ID=-1001234567890
DATABASE_PATH=/app/data/studio_admin.db
OPENAI_MODEL=gpt-4.1-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
BOT_DEFAULT_MODE=outside_working_hours
STUDIO_TIMEZONE=Europe/Moscow
STUDIO_NAME=Название студии
ADMIN_NAMES=Даша,Дарья,Дарья Сергеевна
MAX_KNOWLEDGE_FILE_MB=10
CONFLICT_CONTEXT_MESSAGES=8
CONFLICT_CONFIDENCE_THRESHOLD=0.72
CONFLICT_WARNING_COOLDOWN_SECONDS=300
```

## Режимы работы

- `always` — бот включён вручную и отвечает всегда.
- `outside_working_hours` — бот автоматически отвечает только после окончания смены живого администратора.
- `working_hours_only` — дополнительный режим: бот отвечает только во время смены администратора.
- `off` — бот выключен вручную и не отвечает на вопросы, но модерация и админ-команды остаются.

По умолчанию рабочее время живого администратора:

```text
Пн-Пт: 16:00-22:00
Сб: 10:00-18:00
Вс: выходной
```

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## Команды администратора

- `/start` — старт и кнопочное меню для администратора.
- `/menu` — открыть меню управления режимами.
- `/set_service_chat` — назначить текущий чат сервисным.
- `/add_parent_chat` — назначить текущий чат родительским.
- `/mode` — открыть кнопочное меню режимов.
- `/mode always` — включить круглосуточный режим.
- `/mode outside_working_hours` — отвечать вне работы студии.
- `/mode working_hours_only` — отвечать только в рабочее время.
- `/mode off` — выключить ответы.
- `/hours` — открыть настройку графика живого администратора.

В кнопочном меню можно включить или выключить бота вручную либо выбрать автоматическую работу после смены администратора. Для изменения графика нажмите нужный день и ответьте интервалом в формате `09:00-18:00` или словом `выходной`.

Настройка ответов на каждое сообщение доступна только администраторам в личном чате с ботом. Отправьте боту `/menu`, нажмите «Настроить ответы по чатам», выберите родительскую группу и включите или выключите режим. Настройка действует только для выбранной группы и по умолчанию выключена. Её также можно переключить кнопкой в личном уведомлении администратора о подключении чата. В родительской группе эта настройка не показывается, а обработчики отклоняют попытки изменить её вне личного чата. Доступ дополнительно проверяется по Telegram ID из `ADMIN_IDS`.

Когда настройка включена, бот отвечает на каждое текстовое сообщение, подпись к медиа или голосовое сообщение; на обычные реплики отвечает кратко, а сведения о студии не выдумывает.

Выбранный режим, график и настройка каждой группы хранятся в SQLite и сохраняются после перезапуска. Общий режим работы имеет приоритет: в режиме `off` и во время смены администратора при режиме `outside_working_hours` ответы отключены, но модерация и админ-команды продолжают работать. Ответы на каждое сообщение увеличивают количество запросов к OpenAI API.

## Контекстная модерация конфликтов

В родительских и модерационных чатах бот отправляет последние сообщения переписки в OpenAI и оценивает не отдельные слова, а развитие разговора. Категории анализа: нейтральное сообщение, напряжение, конфликт и оскорбительное поведение. Обычный вопрос, спокойное несогласие, жалоба на услугу, цитата или дружеская шутка не должны считаться конфликтом.

Предупреждение публикуется при категории «конфликт» или «оскорбительное поведение» с уверенностью не ниже `CONFLICT_CONFIDENCE_THRESHOLD`. Для постепенно нарастающего напряжения нужны два последовательных сигнала. Повторное предупреждение в одной группе ограничивается параметром `CONFLICT_WARNING_COOLDOWN_SECONDS`.

При таком срабатывании сообщение пользователя не удаляется. Бот публикует правила общения в группе, сохраняет запись в журнале модерации и отправляет администраторам оценку AI. Сообщения с рекламой и подозрительными ссылками по-прежнему удаляются отдельным фильтром. Контекстная проверка выполняет дополнительный запрос к OpenAI для каждого текстового сообщения или подписи к медиа в подключённых группах.

## Как добавлять знания

1. Откройте личный чат администратора с ботом или сервисный чат.
2. Отправьте туда текст, PDF, Word (`.docx`), Excel (`.xlsx`, `.xls`), изображение или голосовое сообщение.
3. Бот сделает выжимку и предложит добавить материал.
4. Администратор нажимает «Добавить в базу».
5. После этого бот сможет отвечать родителям по этой информации.
